# Changelog

รูปแบบอ้างอิงจาก [Keep a Changelog](https://keepachangelog.com/)
และใช้ [Semantic Versioning](https://semver.org/)

## [5.8.1] — 2026-07

### Added
- **บันทึกเป็น → เลือกหน้าได้**: ตอน Save As เป็น PDF ถามว่าจะเอาทั้งไฟล์ / เฉพาะหน้าปัจจุบัน / ระบุช่วงเอง (เช่น `1-3,5,8-` เรียงลำดับได้ด้วย เช่น `3,1,2`) — ไฟล์ใหม่เก็บคอมเมนต์/ลิงก์/ช่องฟอร์มครบ และยังแก้ไขไฟล์เดิมต่อได้ไม่สลับไฟล์
- **กรอกแบบฟอร์ม PDF (AcroForm)**: คลิกช่องในโหมดแก้ข้อความเพื่อกรอก, checkbox กดสลับได้, หรือเลือกจากรายการช่องทั้งหมดในเมนูเครื่องมือ — ค่าที่กรอก round-trip กับ Acrobat ได้จริง
- **เลือกหลายข้อความพร้อมกัน**: Ctrl+คลิกในโหมดขยับ สะสมหลาย span (กรอบม่วง) แล้วลากหรือกดลูกศรขยับทั้งกลุ่มพร้อมกัน
- **ข้อความยาวตัดบรรทัดอัตโนมัติ**: เพิ่มข้อความใหม่ที่ยาวเกินขอบขวา จะ wrap เป็นย่อหน้าตาม metrics ฟอนต์จริง (ภาษาไทยไม่มีวรรค → ตัดรายตัวอักษรตามมาตรฐาน)
- **ชุดเทสต์อัตโนมัติ** (pytest, 20 เทสต์): ครอบทุกบั๊กที่เคยพบ — ฟอนต์เปลี่ยนตอนขยับ, ตัวหนาสะสม, soft hyphen, บรรทัดข้างเคียงเสียตอนทับกัน, temp leak, undo/save cycle — รัน `python -m pytest tests/`

## [5.7.2] — 2026-07

### Added
- ส่งออกทุกหน้าเป็นรูปภาพ → ได้ **ไฟล์ ZIP เดียว** (แทนการโปรยไฟล์รูปเป็นสิบๆ ไฟล์ลงโฟลเดอร์)

## [5.7.1] — 2026-07

### Changed
- **ขยับข้อความแบบ Acrobat**: แก้ตำแหน่ง (Tm matrix) ใน content stream ตรงๆ ไม่ลบ-เขียนใหม่ — ฟอนต์/สี/ActualText ไม่ถูกแตะแม้แต่ byte เดียว ขยับได้ lossless กับฟอนต์ทุกชนิด (มีระบบ verify + rollback อัตโนมัติถ้าไฟล์โครงสร้างแปลก)
- ย้อนเวอร์ชันแล้ว **บันทึกกลับไฟล์เดิมได้ปกติ** ไม่บังคับ "บันทึกเป็น" อีก (มีสำรองอัตโนมัติก่อนทับเสมอ)

## [5.7.0] — 2026-07

### Fixed
- **Temp font รั่ว**: ไฟล์ฟอนต์ที่ extract ชั่วคราวถูกลบเมื่อปิดไฟล์/ปิดโปรแกรม (เดิมสะสมไม่จำกัด)
- Font cache ไม่ invalidate หลัง undo/save (เสี่ยง glyph ผิดฟอนต์) + cache ชนกันใน merged PDF (เปลี่ยน key เป็น xref)
- **บันทึกทับตัวเองทนต่อความล้มเหลว**: disk เต็ม/ไฟล์ถูก lock กลางทาง → กู้เอกสารในหน่วยความจำกลับมา งานไม่หาย

### Changed
- Cache วัตถุฟอนต์รวมศูนย์ (เร็วขึ้นตอนขยับ/วัดความกว้างซ้ำๆ) + ปรับ ActualText parser เป็น binary search

## [5.6.x] — 2026-07

### Fixed
- ขยับข้อความแล้ว**ฟอนต์เปลี่ยน/หนาขึ้นสะสม** (ไฟล์ Word ภาษาไทย): ซ่อม cmap ของ subset จาก 4 แหล่ง — cmap เดิม + ToUnicode CMap + **ActualText markers** (กู้สระ/วรรณยุกต์ที่ Word compose ทิ้ง เช่น ์ ็ ่ ้) + glyph trace → ขยับด้วยฟอนต์เดิมจากไฟล์ ขนาดเดิม ไม่หนาเอง
- เครื่องหมาย "-" กลายเป็น soft hyphen (U+00AD) หลังขยับ → canonicalize cmap (1 glyph : 1 code point)
- `_match_bundled` สุ่มเลือก Regular/Medium/Light (key เท่ากัน) → เพิ่ม weight class ล็อคน้ำหนักตรง
- ขยับข้อความ**ทับบรรทัดอื่นแล้วเละ**: ลำดับ chain ตอนเขียนบรรทัดข้างเคียงกลับสลับด้าน (ฟอนต์ทดแทนมาก่อนฟอนต์จริง) + faux bold ซ้อน + ไม่คุมความกว้าง — แก้ครบทั้งสามจุด
- ข้อความที่ฟอนต์ทดแทนกว้างกว่าต้นฉบับ → **บีบแนวนอน** (ความสูงตัวอักษรคงเดิม) แทนการลดขนาดฟอนต์

## [4.9.5] — 2026-07

### Added
- ตราประทับข้อความสำเร็จรูป (สำเนาถูกต้อง / ด่วนที่สุด / ลับ / วันที่รับเอกสาร ฯลฯ) เลือกสีได้
- สร้าง QR Code จากลิงก์หรือข้อความ (ฝังไลบรารี `qrcode` ไว้ในโปรเจกต์ ไม่ต้องติดตั้งเพิ่ม)
- ใส่/แก้ไข/ลบ ไฮเปอร์ลิงก์บนข้อความ (คลิกที่คำเพื่อใส่ลิงก์ หรือคลิกลิงก์เดิมเพื่อแก้/ลบ)
- ใส่เลขหน้าอัตโนมัติทุกหน้า (หลายรูปแบบ/ตำแหน่ง)
- ประวัติเวอร์ชันข้ามการปิดโปรแกรม + เตือนก่อนเขียนทับต้นฉบับ (กู้คืนไฟล์เก่าได้)
- คอมเมนต์ 3 แบบ: โน้ต / ลูกศรชี้ / กล่องข้อความ (ลากย้าย-ปรับขนาดได้)
- ปากกาหลายสี + กด Shift ลากเส้นตรงยาว ๆ
- ลายน้ำใหญ่กลางหน้า เอียง 45°

### Changed
- ตัวหนาแบบไม่มีไฟล์ฟอนต์หนา ใช้การเขียนครั้งเดียว (แก้ปัญหาข้อความซ้ำเมื่อย้าย)
- ปุ่มสลับภาษาเด่นชัดขึ้น
- ลิงก์แสดงผลชัดเจน (พื้นฟ้าอ่อน + เส้นใต้น้ำเงิน) และลบออกได้หมดจด

### Fixed
- กรอบเลือกค้างข้ามหน้า / ค้างหลังย้าย-ปรับขนาด-เปลี่ยนเครื่องมือ
- ปุ่มลูกศรขยับข้อความ/รูปไม่ทำงาน (โฟกัสคีย์บอร์ด)
- อาการหน่วงเวลาเลื่อนเมาส์ (แคชผลค้นหา)
